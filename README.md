🌐 Global Civic Intelligence Platform
An advanced, interactive civic intelligence dashboard designed to educate global citizens on election processes, parliamentary structures, and real-time polling data. Built with a high-performance Glassmorphism UI and Agentic AI assistance.

🚀 Live Features
1. Dynamic Global Election Timelines
Context-Aware Data: Real-time polling status for countries like India, USA, and the UK.

2026 Live Tracking: Specifically tracks the April/May 2026 West Bengal Assembly Elections (Phase 2) and global midterms.

2. Segmented Voter Journey (Scroll-Driven)
A guided, step-by-step interactive scroll that categorizes users by their needs:

Future Voters (<18): Educational milestones and pre-registration info.

New Voters: Document checklists (Aadhaar/Passport) and Form 6 filing guides.

Pro Voters: Direct links to electoral rolls and live booth stats.

3. The System Lab
Parliamentary Deep-Dive: Interactive cards for Lok Sabha and Rajya Sabha featuring real member names, positions, and party affiliations.

Constitutional Flowcharts: Visual representation of the democratic hierarchy: Citizen → MP → Majority Party → Prime Minister.

4. Virtual Voting Booth & Play Zone
Voting Simulator: A step-by-step walkthrough of the polling station experience, including VVPAT and Indelible Ink education.

High-IQ Civic Quiz: 10-question interactive challenges with detailed explanations and "Civic Score" reporting.

🛠 Tech Stack
Frontend: React.js / Vite

3D Elements: Three.js / React-Three-Fiber (Map pins and UI models)

Styling: High-performance CSS Glassmorphism

Backend & Auth: Firebase (Google OAuth 2.0)

Intelligence: Agentic AI Mentor integration

📸 Key UI Elements
Antigravity Motion: All UI cards utilize a floating, physics-based motion for a premium feel.

Navigation Hotbar: 3D-effect floating icons at the bottom of the viewport for seamless routing.

Personalized Profile: Firebase-synced profile pages tracking age-based voter eligibility.
